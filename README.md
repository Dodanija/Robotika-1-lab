Automatic Parking Barrier System
This project simulates an automatic parking barrier using Arduino in Tinkercad. Two ultrasonic sensors detect a vehicle entering and leaving the gate. A servo motor controls the barrier, while red, yellow, and green LEDs show whether the gate is closed, moving, or open.

How to Use:
1. Start the simulation in Tinkercad.
2. Move an object within 100 cm of the first ultrasonic sensor.
3. The barrier opens and the yellow LED turns on while the servo is moving.
4. When the barrier is fully open, the green LED turns on.
5. Move the object past the second ultrasonic sensor.
6. After the object moves more than 100 cm away from the second sensor, the barrier closes.
7. When the barrier is fully closed, the red LED turns on again.
